Testing

Tests de prueba

Backend

El backend usa JUnit Platform y dependencias de testing de Spring Boot.

cd backend
./gradlew test
./gradlew jacocoTestReport
  • Tests unitarios de servicios y repositorios.
  • Tests de integración de controladores y base de datos.
  • Pruebas end-to-end de flujos completos.
  • Cobertura mínima objetivo del 70%.

Frontend

La web usa Vitest, Testing Library y jsdom.

cd web
npm run test
npm run test:watch
npm run test:coverage
  • Flujos de login y autenticación.
  • CRUD de proyectos y elementos.
  • Rutas privadas, tarjetas y utilidades del simulador.
  • Mocks de API para probar errores sin depender del servidor real.
