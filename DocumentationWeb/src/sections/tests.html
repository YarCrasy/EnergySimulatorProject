Testing

Tests de prueba

Backend

El apartado de prueba del manual de desarrollo backend valida que la API funcione correctamente antes de integrar cambios en la aplicación web y Android. Las pruebas se ejecutan con Gradle, JUnit Platform y Spring Boot Test, generando además un informe de cobertura con JaCoCo.

cd backend
./gradlew test
./gradlew jacocoTestReport
./gradlew build
  • Pruebas unitarias: comprueban la lógica aislada de servicios, validaciones y cálculos sin depender de la interfaz.
  • Pruebas de integración: verifican controladores, repositorios, serialización JSON y comunicación con la capa de persistencia.
  • Pruebas de API: revisan endpoints REST, códigos HTTP, autenticación JWT y permisos de usuario/administrador.
  • Informe de cobertura: JaCoCo permite revisar qué partes del backend quedan cubiertas por los tests.
  • Resultado esperado: la tarea `test` debe terminar en verde y el informe HTML debe generarse en `backend/build/reports/jacoco/test/html/index.html`.

Frontend

La web usa Vitest, Testing Library y jsdom.

cd web
npm run test
npm run test:watch
npm run test:coverage
  • Flujos de login y autenticación.
  • CRUD de proyectos y elementos.
  • Rutas privadas, tarjetas y utilidades del simulador.
  • Mocks de API para probar errores sin depender del servidor real.
