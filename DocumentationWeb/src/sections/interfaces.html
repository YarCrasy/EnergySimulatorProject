Interfaces

Diseño inicial, mockups y prototipado

El prototipado recoge tanto la aplicación web como la móvil. La web prioriza el trabajo con proyectos y diagramas; Android prioriza consulta, autenticación, perfil y acceso a proyectos desde un dispositivo móvil.

La documentación visual se apoya en capturas reales extraídas de la aplicación desarrollada. Esto permite mostrar el resultado final en lugar de mantener únicamente mockups iniciales.

El prototipo navegable y los diseños iniciales están disponibles en Figma: abrir prototipo en Figma.

Vistas principales

VistaElementos principalesObjetivo de diseño
Login y registroFormularios minimalistas, validación en tiempo real, mensajes claros y navegación entre crear cuenta e iniciar sesión.Reducir errores de entrada y facilitar el acceso al sistema.
Dashboard de proyectosListado de proyectos, fecha de actualización, botón Nuevo Proyecto y menú contextual para abrir o eliminar.Permitir recuperar trabajo anterior y crear simulaciones rápidamente.
Simulador principalCanvas central, catálogo lateral por categorías, buscador, panel de proyecto, panel de propiedades, controles de zoom, bloqueo y centrado.Construir sistemas energéticos de forma visual e interactiva.
Panel de administraciónTablas CRUD de usuarios y elementos, formularios de edición, alta de registros y confirmaciones de eliminación.Mantener usuarios y catálogo sin acceder directamente a la base de datos.
AndroidPantallas nativas para login, proyectos y perfil; WebView para cargar el simulador.Reutilizar el simulador web y ofrecer acceso móvil coherente.

Estados contemplados

  • Carga durante peticiones a API.
  • Error de conexión o credenciales incorrectas.
  • Usuario sin proyectos.
  • Validaciones junto al campo afectado.
  • Confirmación antes de eliminar proyectos, usuarios o elementos.
  • Resultados visibles tras una simulación correcta.
