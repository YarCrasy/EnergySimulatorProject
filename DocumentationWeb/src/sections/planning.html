Metodología de trabajo

  1. GitHub Issues: se usaron issues y subtareas para organizar el trabajo por asignaturas y responsabilidades.
  2. Ramas por persona o tarea: cada miembro trabajó en ramas propias según la tarea asignada.
  3. Reparto flexible: Nataly se centró inicialmente en login/registro y Lingcheng en simulador y conexión backend; después el trabajo fue más síncrono según necesidades.
  4. Seguimiento de avance: las tareas se actualizaban en GitHub para que el equipo pudiera ver progreso, porcentaje completado y estado abierto/cerrado.
  5. Documentación progresiva: la documentación se actualizó con capturas, manuales y decisiones reales del desarrollo.
