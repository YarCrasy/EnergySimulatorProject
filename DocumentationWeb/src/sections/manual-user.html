Manual de usuario

Uso de la aplicación web

Este manual guía el uso de EnergySimulator desde la creación de cuenta hasta la ejecución de simulaciones. Sirve tanto para usuarios convencionales como para administradores, aunque las funciones administrativas solo aparecen con rol admin.

Requisitos del sistema

RequisitoDetalle
Navegador recomendadoGoogle Chrome para mayor estabilidad; también compatible con Firefox, Edge y Safari.
ConexiónConexión estable, preferiblemente 4G o superior, para cargar imágenes, API y resultados sin cortes.
Dispositivos webOrdenador o tablet para una experiencia cómoda en el simulador.
MóvilAndroid 8.0 o superior para la aplicación Android.

Registro e inicio de sesión

  1. Desde la página de inicio, pulsa Iniciar sesión.
  2. Si no tienes cuenta, selecciona Crear cuenta.
  3. Completa nombre, email, fecha de nacimiento y contraseña.
  4. El sistema valida cada campo antes de permitir crear el usuario.
  5. Cuando aparece el mensaje de usuario creado, vuelve al login e inicia sesión.
CampoValidación
Nombre completoMínimo 4 letras y sin números.
EmailFormato válido de correo electrónico y no duplicado.
Fecha de nacimientoNo puede ser una fecha futura.
ContraseñaMínimo 8 caracteres, al menos una mayúscula, una minúscula y un número.

Panel de proyectos

  • El panel muestra todos los proyectos guardados por el usuario.
  • El botón Nuevo Proyecto crea un proyecto y abre el simulador.
  • El menú de cada tarjeta permite abrir o eliminar un proyecto.
  • Al abrir un proyecto se recuperan sus elementos, relaciones y configuración.
  • Eliminar un proyecto requiere confirmación y borra sus nodos y simulaciones asociadas.

Simulador

  1. Abre un proyecto nuevo o existente.
  2. En el catálogo lateral, elige una categoría: generadores, consumidores o almacenadores.
  3. Haz clic en un elemento para añadirlo automáticamente al área de trabajo.
  4. Arrastra el nodo para colocarlo en la posición deseada.
  5. Selecciona un elemento de origen y después un receptor para crear una conexión visual.
  6. Configura propiedades como nombre, potencia y cantidad.
  7. Ajusta latitud, longitud, días de simulación e inclinación de paneles.
  8. Guarda el proyecto o pulsa Simular para calcular resultados.

Nota: al cambiar la cantidad de un elemento no se duplican nodos visualmente; se muestra la cantidad sobre el propio nodo, por ejemplo x2.

Manual de administración

Cuando inicia sesión un administrador, la aplicación muestra funciones para gestionar usuarios y elementos del catálogo. Estas acciones deben realizarse con cuidado porque afectan a datos compartidos por toda la aplicación.

AcciónPasosConsideraciones
NavegarUsa la barra superior para cambiar entre usuarios, receptores y cierre de sesión.Solo aparece si el usuario tiene rol administrador.
Editar usuarioPulsa Editar, revisa el formulario cargado, modifica datos y guarda.La contraseña no se muestra; se puede asignar una nueva si cumple validaciones.
Eliminar usuarioPulsa Eliminar y confirma el aviso.La eliminación es definitiva y actualiza la tabla automáticamente.
Crear usuarioPulsa Nuevo usuario, completa el formulario y guarda.Usa las mismas reglas de validación que el registro público.
Crear elementoAbre Receptores o catálogo, pulsa Nuevo elemento, introduce datos y guarda.Nombre y consumo/potencia son obligatorios; coordenadas X/Y son opcionales.
Editar elementoPulsa Editar en el elemento, cambia sus datos y guarda.Cancelar cierra el formulario sin aplicar cambios.
Eliminar elementoPulsa Eliminar y confirma.Si el elemento está referenciado por proyectos, la base de datos puede impedir borrarlo.

Preguntas frecuentes

PreguntaRespuesta
¿Por qué no puedo iniciar sesión?Comprueba que el email y la contraseña son correctos. Si todavía no tienes cuenta, debes registrarte primero.
¿Cómo mover los elementos en el simulador?Haz clic sobre el elemento y arrástralo con el ratón hasta la posición deseada.
¿Qué navegador es el más adecuado?Se recomienda Google Chrome, aunque también funcionan Firefox, Edge y Safari.
¿Puedo eliminar un proyecto?Sí. En tu lista de proyectos abre el menú contextual y selecciona Eliminar. Se pedirá confirmación.
La simulación no devuelve resultados.Revisa que haya elementos configurados, ubicación válida y conexión a Internet para consultar Open-Meteo.
