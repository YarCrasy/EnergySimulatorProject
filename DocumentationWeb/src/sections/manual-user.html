Manual de usuario

Uso de la aplicación

Este manual guía el uso de EnergySimulator desde el registro inicial hasta la simulación de proyectos y las tareas de administración. Las capturas se han tomado del documento final y muestran las zonas de interacción más importantes.

7.3.5 Registro de usuario

  1. Diríjase a la página de inicio.
  2. Haga clic en Iniciar sesión, que le llevará directamente a la página de login.
  1. Si aún no tiene cuenta, haga clic en Crear cuenta.
  1. Rellene el formulario de registro con los campos solicitados.
  1. Complete los campos solicitados respetando las reglas de validación.
  • El nombre completo no puede tener números y debe tener al menos 4 letras.
  • El correo electrónico debe tener formato válido.
  • La fecha de nacimiento no puede ser futura.
  • La contraseña debe tener al menos 8 caracteres, una mayúscula, una minúscula y un número.
  1. Pulse Crear cuenta.

Nota importante: hasta que no se cumplan todos los requisitos de validación, no se podrá crear el usuario.

7.3.6 Inicio de sesión

  1. Acceda a la página principal y haga clic en Iniciar sesión.
  2. Introduzca el correo electrónico registrado y su contraseña.
  1. Haga clic en Iniciar sesión.

Importante: si se escribe mal el email o la contraseña, no se podrá acceder a la aplicación.

7.3.7 Tus proyectos

Una vez dentro, el usuario será dirigido a la página de proyectos personales. En esta pantalla puede ver una lista de proyectos y crear uno nuevo.

7.3.8 Acciones en proyectos

En cada proyecto se puede abrir el trabajo guardado o eliminarlo desde el menú desplegable. Al eliminar, la aplicación muestra una confirmación para evitar borrados accidentales.

7.3.9 Crear un nuevo proyecto

Para crear un proyecto, pulse el botón verde Nuevo Proyecto. Se abrirá la pantalla de simulador con el área de trabajo y los elementos disponibles.

7.3.9.1 Seleccionar elementos

Los elementos disponibles se encuentran en la barra lateral del simulador. Están agrupados por generadores, consumidores y almacenadores. Al abrir una categoría y hacer clic sobre un elemento, este se añade automáticamente al dashboard.

7.3.9.2 Buscar elementos por nombre

En la barra de herramientas izquierda, debajo del buscador, introduzca el nombre del elemento. La interfaz filtrará los resultados y permitirá seleccionarlo más rápido.

7.3.9.3 Conectar elementos

Seleccione un elemento de origen y después el receptor que desea conectar. La relación se mostrará mediante una línea visual. Los elementos no conectados continuarán sin línea.

7.3 Modificar propiedades de los elementos

Seleccione un nodo para modificar sus datos desde el panel lateral derecho. Puede cambiar nombre, potencia, cantidad y otros valores editables. Cuando se cambia la cantidad, no se duplican nodos visualmente; las unidades se representan sobre el propio elemento.

Controles del lienzo

  • + acerca la pantalla.
  • - aleja la pantalla.
  • El icono central centra la imagen.
  • El candado fija los elementos en el dashboard.

7.4 Ajustes según zona geográfica

Para que el proyecto simule correctamente, configure latitud, longitud, días de simulación e inclinación. Estos datos influyen en el cálculo de radiación, consumo y generación.

7.5 Guardar simulación

Pulse Guardar para conservar los cambios del proyecto. Si todo es correcto, el proyecto aparecerá en la lista de proyectos del perfil. Si hay un error, la interfaz lo indicará en pantalla.

7.6 Ver resultados de la simulación

Después de pulsar Simular, la aplicación ejecuta la simulación del proyecto. Cuando el cálculo termina, el botón Sin resultados cambia a Resultados y queda habilitado para abrir el informe.

  1. Compruebe que el proyecto tiene elementos colocados, conexiones y parámetros geográficos configurados.
  2. Pulse Simular en la barra superior del simulador.
  3. Cuando aparezca el botón Resultados, haga clic sobre él.
  4. Revise el resumen de kWh generados, kWh consumidos y porcentaje de autosuficiencia.
  5. Use la tabla inferior para consultar los valores por hora: generación, consumo, balance, nubosidad e irradiación.
  6. Pulse Cerrar para volver al simulador.

8. Cerrar sesión

Desde la barra de navegación, pulse Cerrar sesión. La aplicación eliminará la sesión activa y volverá a la pantalla de login.

10. Manual de usuario administrador

Cuando inicia sesión como administrador, la aplicación muestra el panel de administración de usuarios. Desde esta pantalla se pueden consultar, crear, editar y eliminar usuarios.

10.1 Navegación

La barra superior permite cambiar entre usuarios y receptores, además de cerrar sesión.

10.2 Editar usuarios

Para editar un usuario, pulse el botón azul Editar en la misma fila. Se abrirá un formulario con los datos del usuario seleccionado, excepto la contraseña.

10.3 Eliminar usuarios

Pulse el botón rojo Eliminar del usuario correspondiente y confirme la operación. Si cancela, no se aplicará ningún cambio.

10.4 Creación de nuevos usuarios

Pulse Nuevo usuario para abrir el formulario. Debe seguir las mismas validaciones que el registro público.

10.5 Crear elemento de consumo

Desde la página de administración de receptores, pulse Nuevo elemento de consumo. Complete nombre y consumo; las posiciones X e Y son opcionales.

10.6 Editar receptores de energía o elementos de consumo

Entre en Receptores, pulse Editar en el elemento deseado, cambie los datos necesarios y guarde. Si decide cancelar, el formulario se cerrará sin cambios.

10.7 Borrar elemento de consumo

Pulse Borrar sobre el elemento de consumo, confirme la operación y la lista se actualizará automáticamente.
