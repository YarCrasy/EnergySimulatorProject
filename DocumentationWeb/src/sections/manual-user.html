Manual de usuario

Uso de la aplicación

Este manual está dirigido a la persona que utilizará el simulador para crear proyectos energéticos, configurar componentes renovables y consultar resultados.

Inicio de sesión y registro

  1. Accede a la pantalla de login.
  2. Introduce correo electrónico y contraseña.
  3. Si todavía no tienes cuenta, abre registro y completa los datos obligatorios.
  4. Tras iniciar sesión, la aplicación carga tus proyectos.

Gestión de proyectos y simulador

  1. Crea un proyecto nuevo.
  2. Añade generadores, consumidores y baterías.
  3. Configura cantidad, consumo, generación o almacenamiento.
  4. Ejecuta la simulación y revisa métricas.
  5. Guarda el proyecto para recuperarlo después.
