Comandos útiles

Estos comandos cubren las tareas habituales durante el desarrollo: arrancar servicios en local, ejecutar pruebas, generar informes de cobertura y crear builds verificables antes de desplegar o entregar una versión.

Backend

Permiten arrancar la API REST de Spring Boot, ejecutar la batería de tests, generar el informe de cobertura JaCoCo y comprobar que el backend compila correctamente.

cd backend
./gradlew bootRun
./gradlew test
./gradlew jacocoTestReport
./gradlew build

Frontend web

Instalan dependencias, levantan el servidor Vite de desarrollo, generan la versión de producción y ejecutan las pruebas del frontend React.

cd web
npm install
npm run dev
npm run build
npm run test

Android

Compilan la aplicación Android en modo debug e instalan el APK generado en un emulador o dispositivo conectado.

cd Android
./gradlew :app:assembleDebug
./gradlew :app:installDebug

Configuración

  • El backend lee la conexión a PostgreSQL desde backend/src/main/resources/application.properties.
  • La variable VITE_API_URL permite cambiar la URL del backend. Si no existe, el frontend usa http://localhost:8080/api en desarrollo.
  • Android define URLs distintas para debug y release desde Android/app/build.gradle.kts.
  • Las claves JWT y credenciales de base de datos deben sustituirse antes de producción.

Convenciones

  • camelCase para variables y métodos.
  • PascalCase para clases y componentes.
  • DocumentationWeb se usa como documentación final navegable, imprimible y mantenida junto al repositorio.
  • Logs con SLF4J usando niveles DEBUG, INFO, WARN y ERROR.
  • Servicios de backend separados de controladores y repositorios.
  • Componentes React reutilizables, con llamadas HTTP centralizadas en la capa api.
  • Tests con patrón Arrange, Act, Assert y mocks para aislar llamadas externas.
  • Cobertura mínima objetivo del 70% en backend.
