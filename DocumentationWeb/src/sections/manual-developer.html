Manual de desarrollador

Entorno local y trabajo técnico

Requisitos previos

  • Git para clonar el repositorio.
  • JDK 25 para el backend.
  • PostgreSQL para la base de datos local.
  • Node.js y npm para Vite.
  • Android Studio y Android SDK para la app móvil.

Backend

cd backend
./gradlew bootRun
./gradlew test
./gradlew build

Frontend web

cd web-refactored
npm install
npm run dev
npm run build
npm run test

Android

cd Android
./gradlew assembleDebug

La variable VITE_API_URL permite cambiar la URL del backend. Si no existe, el frontend usa http://localhost:8080/api en desarrollo.
