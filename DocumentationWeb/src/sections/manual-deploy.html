Manual de deploy

Despliegue de la aplicación

Este manual está dirigido a la persona técnica que instala la solución en el entorno del cliente o en producción.

Base de datos

  • Instalar PostgreSQL y crear energysimulatordb.
  • Crear el usuario de aplicación o adaptar backend/InitBD.sql.
  • Configurar credenciales fuera del repositorio.
psql -U postgres
CREATE DATABASE energysimulatordb;
CREATE USER "SimulatorUser" WITH PASSWORD 'SimulatorUserPassword123';
GRANT ALL PRIVILEGES ON DATABASE energysimulatordb TO "SimulatorUser";

Backend

spring.datasource.url=jdbc:postgresql://localhost:5432/energysimulatordb
spring.datasource.username=SimulatorUser
spring.datasource.password=SimulatorUserPassword123
app.jwt.secret=change-this-secret-key-before-production

Backend local y JAR desplegable

cd backend
./gradlew bootRun
./gradlew bootJar
java -jar build/libs/backend-0.0.1-SNAPSHOT.jar

Builds

cd backend
./gradlew build

cd web
npm install
npm run build
npm run preview

cd Android
./gradlew :app:assembleDebug
./gradlew :app:bundleRelease

Para release, Android usa https://dam.yarcrasy.com/api/ como backend y https://dam-project.yarcrasy.com como web base.

Producción

  • Servir el frontend web como archivos estáticos desde web/dist.
  • Publicar el backend detrás de HTTPS y un proxy inverso si se despliega en servidor propio.
  • Configurar CORS para permitir únicamente los dominios de la web y de las apps autorizadas.
  • Cambiar spring.jpa.hibernate.ddl-auto a validate o none cuando existan datos reales.
  • Guardar copias de seguridad periódicas de PostgreSQL.

Checklist final

  • Base de datos creada y con permisos correctos.
  • JWT secret sustituido por una clave segura.
  • Backend responde en /api.
  • Frontend apunta a la URL pública correcta mediante VITE_API_URL.
  • APK/AAB Android generado con configuración de release.
  • La app Android está firmada con keystore de release si se va a publicar.
  • Login, listado de proyectos, administración y simulación probados tras el despliegue.
